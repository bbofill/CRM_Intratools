# Module 7 - Distribution Lists v1.3

## Introducción

Este módulo muestra un modal de selección de condiciones generales que pueda cumplir un trabajador, y permite exportar un csv con un listado de sus correos electrónicos, o bien enviar una notificación de CRMIntratools.

Las listas de distribución creadas son visibles por todo el mundo con rango `Support` en adelante. 

Cada persona puede modificar y eliminar sus propias listas, pero solo los administradores y managers pueden eliminar las de todo el mundo. Por ello, existe la opción de duplicar, por si alguien quiere crear una lista similar a la de otra persona pero con algún campo modificado.

## Base de datos

Las tablas que gestiona este módulo son:

- **Distribution_lists** guarda toda la información relativa a la lista de distribución.

Para realizar la comprobación de condiciones y devolver los correos electrónicos, este módulo también accede a las diferentes tablas relativas a trabajadores (people, contracts, people_group, etc.)

## Endpoints

Todos los endpoints están comentados en el código con su correspondiente funcionalidad en el fichero `api.go`. A destacar, están todos los endpoints relacionados con la creación, modificación o borrado de las listas de difusión:
- createNewList
- getList: devuelve la información de una lista en concreto
- updateList
- duplicateList
- deleteList

Otros endpoints relevantes son:
- **getLists** devuelve la lista de todas las listas de distribución.
- **exportList** devuelve la lista de correos el FE.
- **notificationToList** envia una notificación interna a los miembros de la lista.
